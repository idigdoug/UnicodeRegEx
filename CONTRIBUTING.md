# Contributing to UnicodeRegEx

Thanks for your interest in the project — suggestions and feature requests are
welcome!

## Ideas, suggestions, and feature requests

Open an [issue](https://github.com/idigdoug/UnicodeRegEx/issues) describing what
you'd like to see. Bug reports, feature ideas, and general suggestions are all
appreciated. There's no formal template — just enough detail to understand the
scenario is plenty.

## Pull requests

PRs are welcome too. A few things that help:

- Keep changes focused, and match the style of the surrounding code.
- Make sure the solution builds and the tests pass (see **Building** in the
  [README](README.md); tests live in [`test/`](test/) and
  [`managed_test/`](managed_test/)).
- For anything larger than a small fix, opening an issue first to discuss the
  approach is a good idea.
